Критерии хорошего проекта

Отмечено 0 из 18
👤 ученик (самопроверка) + учитель ⚙️ проектная технология

Проблема и цель

  • Проблема сформулирована чётко и понятно.
  • Проблема интересна и значима для автора.
  • Цель проекта ясна.
  • Есть гипотеза (если проект исследовательский).

Планирование

  • Составлен план работы.
  • Определены этапы.
  • Распределены роли (если проект групповой).
  • Установлены сроки.

Реализация

  • Собраны данные из разных источников.
  • Проведены расчёты, измерения, эксперименты.
  • Использованы математические методы.
  • Есть таблицы, графики, схемы.

Продукт

  • Продукт создан.
  • Продукт имеет практическую ценность.
  • Продукт понятен аудитории.
  • Продукт оформлен аккуратно.

Презентация и рефлексия

  • Проведена презентация.
  • Даны ответы на вопросы.
  • Проведена рефлексия: что получилось, что нет.
  • Определены перспективы.

15–12 — хорошо.
11–8 — нужно доработать.
меньше 8 — проект не завершён.

Критерии хорошего исследования

👤 ученик + учитель ⚙️ исследовательская технология

Проблема и гипотеза

  • Проблема сформулирована.
  • Гипотеза сформулирована.
  • Гипотеза проверяемая.
  • Понятно, что именно проверяется.

Планирование исследования

  • Определены методы исследования.
  • Определены источники данных.
  • Составлен план.
  • Определены сроки.

Сбор данных

  • Данные собраны.
  • Данные достоверны.
  • Использованы разные источники.
  • Данные систематизированы.

Анализ и вывод

  • Проведён анализ данных.
  • Сделаны расчёты.
  • Построены таблицы, графики.
  • Сформулирован вывод.
  • Подтвердилась или опровергнута гипотеза.

Рефлексия

  • Что было трудным?
  • Что помогло?
  • Чему научился?
  • Что бы изменил?

Критерии хорошего поиска

Отмечено 0 из 16
👤 ученик + учитель ⚙️ поисковая технология

Задача и понимание

  • Задача понятна.
  • Готового алгоритма нет.
  • Понятно, что нужно найти.
  • Определены исходные данные.

Пробы и гипотезы

  • Предложены разные способы.
  • Сделаны пробы.
  • Проанализированы ошибки.
  • Выбрана лучшая гипотеза.

Решение

  • Найден способ решения.
  • Способ проверен на примерах.
  • Способ работает.
  • Способ можно применить к другим задачам.

Рефлексия

  • Что помогло найти способ?
  • Какие пробы были ошибочными?
  • Почему?
  • Чему научился?

Анализ урока с использованием технологии

Отмечено 0 из 20
👤 учитель, студент-будущий учитель ⚙️ все три технологии

Определение технологии

  • Какая технология использована? (проект / поиск / исследование)
  • Обосновано, почему именно она.
  • Понятно, что лежит в основе (проблемная ситуация).

Проблемная ситуация

  • Создана проблемная ситуация.
  • Она интересна ученикам.
  • Она посильна.
  • Она запускает деятельность.

Роль учителя

  • Учитель — фасилитатор, а не транслятор.
  • Задаёт наводящие вопросы.
  • Не даёт готовых ответов.
  • Направляет, но не решает за учеников.

Деятельность учеников

  • Ученики активны.
  • Есть пробы и ошибки.
  • Есть самостоятельная работа.
  • Есть продукт / вывод / найденный способ.

Рефлексия

  • Проведена рефлексия.
  • Ученики осознали, что делали.
  • Ученики увидели результат.
  • Определены перспективы.

Самооценка работы в группе

Отмечено 0 из 20
👤 ученик (после групповой работы) ⚙️ проектная / поисковая / исследовательская

Мой вклад

  • Я предлагал(а) идеи.
  • Я выполнял(а) свою часть работы.
  • Я доводил(а) дело до конца.
  • Я помогал(а) товарищам.

Работа в команде

  • Я слушал(а) других.
  • Я не перебивал(а).
  • Я аргументировал(а) свою позицию.
  • Я принимал(а) чужую точку зрения, если она была доказана.

Решение конфликтов

  • Я не ссорился(ась) с товарищами.
  • Я помогал(а) разрешать споры.
  • Я предлагал(а) компромиссы.
  • Я сохранял(а) доброжелательный тон.

Результат

  • Наша группа достигла цели.
  • Продукт / вывод / способ готовы.
  • Я доволен(льна) результатом.
  • Я готов(а) работать в этой группе снова.

Рефлексия

  • Что мне удалось лучше всего?
  • Что нужно улучшить?
  • Чему я научился(ась) в группе?
  • Что я сделаю иначе в следующий раз?

Критерии хорошего рабочего листа

Отмечено 0 из 25
👤 учитель (самопроверка перед уроком) ⚙️ все три технологии

Поисковая технология

  • Есть жизненная ситуация, понятная ученику.
  • Задача не решается по готовому шаблону.
  • Есть место для проб и ошибок.
  • Есть подсказка, но не готовый ответ.
  • Ученик сам формулирует способ решения.

Исследовательская технология

  • Есть гипотеза.
  • Есть 3+ примера для проверки.
  • Есть «хитрые» случаи, которые ломают шаблон.
  • Есть анализ результатов.
  • Есть вывод.

Проектная технология

  • Есть цель продукта.
  • Есть план работы.
  • Есть критерии оценки продукта.
  • Есть презентация.
  • Есть рефлексия.

Структура и понятность

  • Инструкция для ученика написана понятно.
  • Каждый этап подписан.
  • Есть место для ответов ученика.
  • Лист не перегружен текстом.
  • Есть итоговый вывод.

Обратная связь

  • Ученик может сам проверить себя.
  • Есть критерии самооценки.
  • Есть вопросы для рефлексии.
  • Есть возможность вернуться и исправить.
📊 Итоговая оценка
25–22 — рабочий лист отличный.
21–17 — хороший.
16–12 — есть что улучшить.
меньше 12 — рабочий лист не соответствует технологиям.
